```

    包含3段素材 + 背景音乐 + 字幕

AI 智能编排：

🎬 1. 创建剪映草稿
   ✓ 初始化项目
   ✓ 设置画布：1080x1920 (竖屏)

🎞️ 2. 导入素材
   ✓ 视频1：手冲过程 (0-10s)
   ✓ 视频2：拉花特写 (10-20s)
   ✓ 视频3：成品展示 (20-25s)

🎵 3. 添加音乐
   ✓ 调用 Suno 生成轻快背景乐
   ✓ 添加到音频轨道
   ✓ 音量：60%

📝 4. 添加字幕
   ✓ 0-10s: "第一步：准备器具"
   ✓ 10-20s: "第二步：冲泡咖啡"
   ✓ 20-25s: "完成！"

✨ 5. 特效处理
   ✓ 转场效果：淡入淡出
   ✓ 滤镜：暖色调
   ✓ 速度：关键部分1.2倍速

💾 6. 导出草稿
   ✓ 保存到本地
   ✓ 可在剪映中继续编辑
```

## 工具调用流程

### 创建草稿

```json
{
  "tool": "createDraft",
  "arguments": {
    "draftName": "咖啡教程_20260105",
    "canvas": {
      "width": 1080,
      "height": 1920
    }
  }
}
```

### 添加视频片段

```json
{
  "tool": "addVideo",
  "arguments": {
    "draftId": "draft_abc123",
    "videoPath": "/path/to/video1.mp4",
    "startTime": 0,
    "duration": 10000
  }
}
```

### 添加字幕

```json
{
  "tool": "addSubtitle",
  "arguments": {
    "draftId": "draft_abc123",
    "text": "第一步：准备器具",
    "startTime": 0,
    "duration": 10000,
    "style": {
      "fontSize": 48,
      "color": "#FFFFFF"
    }
  }
}
```
