# 互动操作示例

## 示例 1：发表评论

### 场景

给喜欢的笔记发表评论

### 对话示例

```
你：给这条笔记评论："写得真好，学习了！"
    笔记 ID：64abc123

AI：正在发布评论...
    [调用 postComment 工具]

    ✅ 评论发表成功
    内容：写得真好，学习了！
    时间：刚刚
```

### 工具调用

```json
{
  "tool": "postComment",
  "arguments": {
    "noteId": "64abc123",
    "content": "写得真好，学习了！"
  }
}
```

### 返回结果

```json
{
  "code": 0,
  "success": true,
  "data": {
    "comment_id": "comment_987",
    "content": "写得真好，学习了！",
    "create_time": "2026-01-05 15:30:00"
  }
}
```

## 示例 2：@用户评论

### 场景

在评论中提及其他用户

### 对话示例

```
你：评论："@小红 @小明 你们也来看看这个"
    笔记：64abc123

AI：正在发布评论...
    [调用 postComment，包含 at_users 参数]

    ✅ 评论成功，已@2位用户
```

### 工具调用

```json
{
  "tool": "postComment",
  "arguments": {
    "noteId": "64abc123",
    "content": "@小红 @小明 你们也来看看这个",
    "atUsers": [
      { "userId": "user1", "nickname": "小红" },
      { "userId": "user2", "nickname": "小明" }
    ]
  }
}
```

## 示例 3：批量互动

### 场景

对搜索结果的前几条笔记进行互动

### 对话示例

```
你：搜索"咖啡教程"，给前5条都点赞和评论

AI 智能执行：
    ✓ 搜索笔记
    ✓ 获取前5条
    ✓ 逐条发表评论："很实用的教程！"

    执行结果：
    1. note_001 - ✅ 评论成功
    2. note_002 - ✅ 评论成功
    3. note_003 - ✅ 评论成功
    4. note_004 - ✅ 评论成功
    5. note_005 - ✅ 评论成功
```

### AI 自动编排

```python
# AI 内部逻辑（伪代码）
search_result = searchNotes("咖啡教程")
top_5 = search_result[:5]

for note in top_5:
    postComment(note.id, "很实用的教程！")
    sleep(2)  # 智能间隔，避免限流
```

## 互动策略

### 自然间隔

```
AI 自动处理：
- 单次评论：立即执行
- 批量评论：间隔2-5秒
- 大量操作：建议分批次
```

### 内容多样化

```
你：给10条笔记都评论

AI 会自动：
- 生成不同的评论内容
- 避免重复
- 模拟真人互动
```

### 错误处理

```
场景：评论被限流

AI 自动应对：
✓ 检测到限流 (429错误)
✓ 等待60秒后重试
✓ 如果继续失败，建议稍后再试
```

---

## 注意事项

> ⚠️ **频率控制**：避免短时间大量互动，可能触发平台风控

> 💡 **内容质量**：评论内容要真实自然，避免广告和敏感词

> 🔒 **账号安全**：使用真实 Cookie，定期检查登录状态
