# 用户信息示例

## 示例 1：获取用户主页

### 场景

查看某个用户的主页信息和作品

### 对话示例

```
你：查看用户主页，userId: 5f8a7b2c3d

AI：正在获取用户信息...
    [调用 getUserProfile 工具]

    👤 用户主页
    昵称：咖啡研究所
    简介：专注咖啡文化分享

    数据：
    📊 粉丝：12.3k
    📝 笔记：156 篇
    👍 获赞：45.6k

    最近作品：
    1. 手冲咖啡完全指南
    2. 咖啡豆选购攻略
    3. 拉花入门教程
```

### 工具调用

```json
{
  "tool": "getUserProfile",
  "arguments": {
    "userId": "5f8a7b2c3d",
    "num": 10
  }
}
```

### 返回结果

```json
{
  "code": 0,
  "success": true,
  "data": {
    "user_id": "5f8a7b2c3d",
    "nickname": "咖啡研究所",
    "desc": "专注咖啡文化分享",
    "fans": 12300,
    "notes": 156,
    "likes": 45600,
    "recent_notes": [...]
  }
}
```

## 示例 3：浏览用户作品列表

### 场景

翻页查看用户的所有作品

### 对话示例

```
你：查看这个用户的更多作品

AI：为您加载更多...
    [调用 getUserProfile，增加游标参数]

    📚 作品列表（第2页）
    11. 咖啡拉花进阶技巧
    12. 意式浓缩萃取参数
    13. 咖啡器具推荐合集
    ...
```

### 智能翻页

```
你：继续往下翻
AI：[自动管理游标，加载下一页]

你：回到第一页
AI：[重置游标，返回首页]
```

## 实用技巧

### 批量查看多个用户

```
你：对比这三个用户的数据：
    - user1: 5f8a7b2c3d
    - user2: 6g9b8c3e4f
    - user3: 7h0c9d4f5g

AI 会依次调用：
✓ getUserProfile(user1)
✓ getUserProfile(user2)
✓ getUserProfile(user3)
然后整理成对比表格
```

### 关注趋势分析

```
你：这个用户最近发布频率如何？

AI：分析作品时间戳...
    该用户：
    - 近7天发布：3篇
    - 近30天发布：15篇
    - 平均发布频率：每2天1篇
```
