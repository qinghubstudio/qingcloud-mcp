# 搜索与浏览示例

## 示例 1：搜索笔记

### 场景

搜索小红书上关于"咖啡"的热门笔记

### 对话示例

```
你：搜索关于咖啡的笔记

AI：好的，我来帮你搜索。
    [调用 searchNotes 工具]

    找到 20 条相关笔记：
    1. 【咖啡店探店】上海最文艺的5家咖啡馆
       👍 2.3k  💬 156
    2. 手冲咖啡入门教程｜新手必看
       👍 1.8k  💬 89
    3. 咖啡拉花技巧分享～
       👍 1.5k  💬 67
    ...
```

### 工具调用

```json
{
  "tool": "searchNotes",
  "arguments": {
    "keyword": "咖啡",
    "page": 1,
    "page_size": 20
  }
}
```

### 返回结果

```json
{
  "code": 0,
  "success": true,
  "data": {
    "items": [
      {
        "note_id": "64abc123",
        "title": "咖啡店探店",
        "desc": "上海最文艺的5家咖啡馆...",
        "likes": 2300,
        "comments": 156
      }
    ],
    "total": 20
  }
}
```

## 示例 2：查看推荐内容

### 场景

获取小红书首页推荐内容

### 对话示例

```
你：给我看看首页推荐的内容

AI：为您获取首页推荐...
    [调用 getFeed 工具]

    当前推荐内容：
    - 冬日穿搭｜今天这样穿超显瘦
    - 护肤分享｜我的冬季护肤routine
    - 美食推荐｜这家火锅必须试试
```

### 工具调用

```json
{
  "tool": "getFeed",
  "arguments": {
    "num": 10,
    "category": "homefeed_recommend"
  }
}
```

## 示例 3：获取笔记详情

### 场景

查看某条笔记的完整信息

### 对话示例

```
你：查看这条笔记的详细内容：64abc123

AI：正在获取笔记详情...
    [调用 getNoteDetail 工具]

    📝 笔记详情
    标题：咖啡店探店｜上海最文艺的5家
    作者：@咖啡爱好者
    发布时间：2026-01-03

    内容：
    今天给大家分享上海我最爱的5家咖啡馆...

    数据：
    👍 点赞 2.3k
    💬 评论 156
    ⭐ 收藏 890
```

### 工具调用

```json
{
  "tool": "getNoteDetail",
  "arguments": {
    "noteId": "64abc123"
  }
}
```

## 高级技巧

### 组合搜索条件

```
你：搜索最近一周关于"手冲咖啡"的热门笔记

AI 自动理解：
- 关键词：手冲咖啡
- 排序：按热度
- 时间：最近（虽然当前版本可能不支持时间过滤，但 AI 会尽力满足）
```

### 上下文关联

```
你：搜索咖啡笔记
AI：✓ 找到 20 条

你：看第三条
AI：✓ 获取第三条笔记详情

你：作者还发了什么？
AI：✓ 获取该作者的其他作品
```
