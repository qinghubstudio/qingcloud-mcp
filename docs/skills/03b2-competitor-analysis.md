## 竞品账号分析

### 场景：对比 3 个同类账号

```
你：对比分析这3个咖啡博主：
    @咖啡研究所
    @手冲达人
    @咖啡小白课堂

AI 执行：

👥 1. 数据采集
   ✓ 获取3个账号的主页数据
   ✓ 分析最近30天发布内容
   ✓ 统计互动数据

📊 2. 对比报告

| 指标 | 咖啡研究所 | 手冲达人 | 咖啡小白课堂 |
|------|-----------|---------|-------------|
| 粉丝数 | 12.3k | 8.5k | 15.2k |
| 发布频率 | 2天/篇 | 3天/篇 | 1天/篇 |
| 平均点赞 | 856 | 645 | 1203 |
| 互动率 | 6.9% | 7.6% | 7.9% |
| 主要内容 | 专业教程 | 器具测评 | 入门指南 |

💡 3. 策略建议

   优势方向：
   ✓ "咖啡小白课堂"互动率最高
     → 入门内容更受欢迎

   ✓ "手冲达人"虽粉丝少但互动率高
     → 垂直内容有价值

   建议：
   - 保持日更或隔日更
   - 侧重新手友好内容
   - 增加实用教程比例
```

## 热门笔记深度分析

### 场景：拆解爆款笔记

```
你：分析这条爆款笔记的成功要素：64abc123

AI 分析：

📝 笔记信息
   标题：3分钟学会手冲咖啡｜新手零失败
   点赞：2.3k
   收藏：1.8k
   评论：156

✨ 成功要素

1. 标题策略
   ✓ 包含时间承诺(3分钟)
   ✓ 降低门槛(零失败)
   ✓ 明确受众(新手)

2. 内容结构
   ✓ 开头：痛点共鸣
   ✓ 中间：分步教程
   ✓ 结尾：避坑提示

3. 视觉设计
   ✓ 封面：鲜明对比
   ✓ 图片：步骤清晰
   ✓ 文字：简洁易读

4. 发布时机
   ✓ 晚上8点发布
   ✓ 周末流量高峰

💡 可复制的模板
   标题：[时间]学会[技能]｜[人群][结果]
   例如：5分钟学会拉花｜小白秒上手
```
