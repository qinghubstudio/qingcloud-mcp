# Prompt 工程最佳实践

## 提示词优化技巧

### 1. 明确具体的指令

```
❌ 不好的提示：
"发布笔记"

✅ 更好的提示：
"发布一篇关于手冲咖啡的小红书笔记，
包含3张高质量配图，
标题要吸引人，
内容800字左右"
```

### 2. 提供充足上下文

```
❌ 缺少上下文：
"分析这个数据"

✅ 包含上下文：
"分析我这个咖啡账号最近7天的数据，
重点关注互动率和发布时间的关系，
目标是优化发布策略"
```

### 3. 分步骤描述

```
✅ 清晰的步骤：
"帮我完成以下任务：
1. 搜索'咖啡教程'相关笔记
2. 找出点赞最高的前10条
3. 分析它们的共同特点
4. 生成一份分析报告"
```

## 常见场景的 Prompt 模板

### 内容发布

```
模板：
发布[主题]的小红书笔记
- 图片：[数量]张，风格[描述]
- 文案：[字数]字，语气[风格]
- 话题：[相关话题]
- 定时：[发布时间]

示例：
发布"冬日咖啡"的小红书笔记
- 图片：3张，温馨治愈风格
- 文案：500字，轻松亲切语气
- 话题：#咖啡 #冬日温暖
- 定时：今晚8点发布
```

### 数据分析

```
模板：
分析[对象]的[维度]数据
- 时间范围：[起止时间]
- 关注指标：[具体指标]
- 输出格式：[表格/图表/文字]

示例：
分析我的账号的内容表现数据
- 时间范围：最近30天
- 关注指标：点赞、评论、收藏、转发
- 输出格式：Excel表格 + 趋势图
```

### 批量操作

```
模板：
批量[操作]，满足条件[筛选条件]
- 数量：[具体数量]
- 频率：[时间间隔]
- 安全：[风控要求]

示例：
批量评论，筛选条件是"咖啡教程"标签
- 数量：每天最多50条
- 频率：每条间隔3-5秒
- 安全：避免重复内容，模拟真人行为
```

## 上下文管理

### 引用前文

```
✅ 有效的上下文引用：

你：搜索咖啡笔记
AI：✓ 找到20条

你：看第一条的详情
AI：✓ 显示详情

你：给它点赞
AI：（理解"它"指第一条笔记）✓ 点赞成功

你：作者还发了什么？
AI：（理解"作者"是第一条笔记的作者）✓ 显示作品列表
```

### 明确指代

```
❌ 模糊指代：
"分析它的数据"

✅ 明确指代：
"分析笔记ID 64abc123 的数据"
或
"分析刚才搜索结果第一条的数据"
```

## 结果优化

### 指定输出格式

```
✅ 明确格式要求：

"把搜索结果整理成表格，包含：
- 标题
- 作者
- 点赞数
- 发布时间
按点赞数降序排列"

AI 输出：
| 标题 | 作者 | 点赞 | 时间 |
|------|------|------|------|
| 手冲咖啡教程 | @咖啡研究所 | 2.3k | 01-03 |
| 拉花技巧 | @手冲达人 | 1.8k | 01-04 |
...
```

### 控制详细程度

```
简洁版：
"简单总结这篇笔记的要点"

详细版：
"详细分析这篇笔记：
- 标题策略
- 内容结构
- 视觉设计
- 互动数据
- 成功要素
- 可复用的技巧"
```

## 高级技巧

### 角色扮演

```
优化前：
"帮我写一篇咖啡笔记"

优化后：
"你是一个有5年经验的小红书咖啡博主，
擅长写新人友好的教程内容，
语气轻松幽默但专业，
请写一篇关于手冲咖啡的入门教程"
```

### 示例引导

```
提供示例：
"仿照这个风格写一篇笔记：

【示例】
标题：3分钟学会拉花｜小白秒上手
开头：还在为拉花发愁吗？今天教你最简单的方法...
结构：痛点 + 步骤 + 避坑 + 总结

请写一篇关于手冲咖啡的，保持相同风格"
```

### 迭代优化

```
迭代过程：

Round 1:
你：写一篇咖啡笔记
AI：[生成初稿]

Round 2:
你：标题再吸引人一些
AI：[优化标题]

Round 3:
你：加入更多数据和技巧
AI：[补充内容]

Round 4:
你：很好，就用这个发布
AI：✓ 发布成功
```

## 错误处理提示

### 遇到错误时的沟通

```
✅ 有效的错误处理对话：

AI：❌ Cookie 已失效，无法搜索

你：好的，我重新导入 Cookie
    [提供新的 Cookie]

AI：✓ Cookie 已更新，正在重试...
    ✓ 搜索成功
```

### 澄清需求

```
AI 的澄清问题：

AI：检测到批量操作，为了避免风控，
    请确认：
    1. 每次操作间隔多久？(建议3-5秒)
    2. 总数量限制？(建议<100)
    3. 是否需要随机化？(建议是)

你：间隔5秒，总数50，需要随机化

AI：✓ 了解，开始执行...
```
