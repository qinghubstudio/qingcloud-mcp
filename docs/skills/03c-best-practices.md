## 核心原则

### 1. 确定性与灵活性平衡

```
MCP Tools 层：保持确定性
✓ 明确的输入输出
✓ 可预测的执行结果

AI Agent 层：发挥灵活性
✓ 智能决策
✓ 自适应调整
```

### 2. 安全第一

```
✓ 敏感信息加密存储
✓ 操作审计日志
✓ 关键操作人工确认
```

### 3. 性能优先

```
✓ 避免频繁 API 调用
✓ 合理使用缓存
✓ 异步处理长任务
```
